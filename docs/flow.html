4 System Map (simplified)

Modular monolith now; extract services when load demands. All open-source & self-hosted.

Clients

  • Q-School Learn (web)
  • Q-School Console (admin/CRM/ERP)
  • Q-School app (Expo, iOS + Android)

API & Workers

  • NestJS core API + tRPC
  • Socket.IO realtime
  • BullMQ: transcode, reminders, CRM syncs

Data

  • PostgreSQL 17 + PgBouncer
  • Redis 7 (cache, queues)
  • MinIO (videos, recordings)
  • Meilisearch (search)

Integrations

  • Meta Graph + WhatsApp Cloud API
  • Chatwoot inbox · Listmonk
  • Cal.com · Frappe HR · Metabase
  • Razorpay gateway
